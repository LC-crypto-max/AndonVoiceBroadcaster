技术设计文档

1.本应用基于车间目前现有的MES系统安灯语音播报，开发出一个winform的简易软件，用于操作员日常工作。
2.本应用需要实现以下的功能：
2.2 实现安灯语音播报的音量调节功能，包括音量的大小调节。
2.3 实现安灯语音播报的音色调节功能，包括音色的选择。
2.4 实现安灯语音播报的语速调节功能，包括语速的快慢调节。
2.5 实现安灯语音播报的播放暂停功能，包括播放的暂停和继续。
2.6 实现安灯语音播报的播放进度条功能，包括播放的进度条显示。
2.7 实现安灯语音播报的数据同步功能，播放完成后播放进度同步回写到MES系统数据库中。
2.8 实现安灯语音播报的车间筛选功能，可以在界面输入车间名称或者车间ID，然后点击查询按钮，查询出该车间对应的安灯语音播报数据。
2.9 实现安灯语音播报的时间限制功能，只可以在上班时间进行播放，下班时间不能进行播放。
2.10 实现安灯语音播报的日志记录功能，记录用户的播放配置，实现一次配置后，下次启动软件时，自动加载上一次的播放配置。
2.11 实现安灯语音播报的功能，实现开机后自动启动软件
2.12 实现应用可以选择退出，退出后台进程自动关闭，不产生残留
2.13 实现该应用的无感知启动，减少用户自动配置，或者打开应用的频率，当做一个后台进程使用
2.14 实现安灯语音播报的工厂选择（可做成下拉框形式），车间选择（也做成下拉框形式），车间选择中读取所有的车间名称和对应ID，供操作人员选择进行播报，这个是相对人性化的设计。对现有的车间ID或名称选择进行改进，然后优化下格式



## 实施注意事项

### 1. 准备独立的可执行文件

- 使用 Release 配置构建项目，生成独立的 `AndonVoiceBroadcaster.exe` 文件
- 构建命令：`dotnet msbuild AndonVoiceBroadcaster.csproj -t:Rebuild -p:Configuration=Release -p:Platform=AnyCPU`
- 构建输出位于 `bin\Release\` 目录下

### 2. .NET Framework 4.8 环境依赖

- 本应用基于 .NET Framework 4.8 开发，运行时需要目标电脑安装该框架
- Windows 10 1903 及以上版本已内置 .NET Framework 4.8
- Windows 7/8/8.1 需要手动安装
- 安装包下载地址：https://dotnet.microsoft.com/zh-cn/download/dotnet-framework/net48
- 启动脚本 `启动程序.bat` 会自动检测 .NET Framework 4.8 是否安装
- 检测方式：检查注册表 `HKLM\SOFTWARE\Microsoft\NET Framework Setup\NDP\v4\Full` 下的 Release 值是否为 528040

### 3. 部署包打包与分发

#### 部署包结构
```
AndonVoiceBroadcaster/
├── AndonVoiceBroadcaster.exe    # 主程序（Release 构建）
├── 启动程序.bat                  # 启动脚本（含环境检查）
├── 部署说明.txt                  # 部署说明文档
├── audio/
│   └── AlarmMusic.wav           # 提示音文件
└── config/
    └── appsettings.json         # 默认配置文件
```

#### 打包方式
- 运行 `build-deploy.ps1` PowerShell 脚本自动构建并打包
- 脚本执行步骤：
  1. 执行 Release 构建
  2. 创建部署目录结构
  3. 复制必要文件（exe、配置、音频）
  4. 生成 zip 压缩包
- 生成的压缩包位于项目根目录：`AndonVoiceBroadcaster_Deploy.zip`

#### 分发方式
- 将 zip 压缩包发送给操作员
- 操作员解压到任意目录（建议：D:\AndonVoiceBroadcaster）
- 双击运行 `启动程序.bat`
- 首次运行配置 MES 地址、账号密码和终端编号

### 4. 其他注意事项

- **权限要求**：程序使用当前用户的 DPAPI 加密存储凭据，不需要管理员权限
- **开机启动**：通过写入当前用户注册表实现，不需要管理员权限
- **中文语音**：需要目标电脑安装 `zh-CN` 中文语音包
- **提示音文件**：`AlarmMusic.wav` 需要与 exe 同目录下的 audio 文件夹中
- **配置文件**：首次运行后会在当前目录下创建 `data/credentials.dat`（加密凭据）和 `logs/`（日志目录）
- **单实例保护**：同一台电脑只能运行一个实例，避免重复播报
