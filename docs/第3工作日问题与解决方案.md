# 安灯语音播报 WinForms 项目——第 3 工作日问题与解决方案

## 一、项目进度概况

- 计划周期：5 个工作日
- 当前进度：第 3 个工作日
- 项目目标：使用常驻 Windows 车间电脑上的 WinForms 程序替代操作不便的 PDA 播报页面，在不长期占用主界面的情况下，自动获取 MES 安灯播报任务并通过车间喇叭进行中文语音播报。
- 当前阶段成果：MES 登录、车间解析、待播报任务轮询、播放次数回写、托盘最小化和异常重试控制已形成闭环；设置界面的车间选择功能已从手动输入改为可视化双列表选择。

## 二、第 3 工作日重点问题与解决方案

### 1. 设置界面车间选择体验不佳，用户需要手动输入车间 ID 或名称

**问题表现**

原设置界面使用单行 TextBox 让用户手动输入车间 ID 或名称，用逗号分隔。这种方式存在以下问题：
- 用户需要记住车间 ID 或名称，容易输入错误
- 无法直观看到有哪些车间可选
- 输入格式容易出错（逗号、中文逗号、分号混用）

**解决方案**

- 将单行 TextBox 替换为双列表选择器：左侧显示可用车间，右侧显示已选车间
- 点击"刷新车间列表"按钮后，从 MES 接口 `/mes/md/workshop/listAll` 获取所有车间数据
- 支持单个添加/移除和全部添加/移除操作
- 显示格式为 `车间ID - 车间名称`，便于用户识别
- 保存时自动从已选列表中提取车间 ID 和名称

**处理状态：已解决并通过构建。**

### 2. 设置界面布局问题导致控件不可见

**问题表现**

在优化车间选择界面时，多次出现布局问题：
- 保存/取消按钮被遮挡不可见
- 双列表之间的操作按钮显示异常或丢失
- 表格行数和表单尺寸不匹配导致控件溢出

**解决方案**

- 将表单宽度从 650 调整为 700，高度从 445 调整为 550
- 表格行数从 10 增加到 13，确保所有控件都有足够空间
- 将操作按钮从竖直排列改为水平排列，避免空间不足问题
- 按钮区域使用 FlowLayoutPanel 确保按钮自动排列
- 刷新按钮跨两列显示，确保可见性

**处理状态：已解决并通过构建。**

### 3. 车间选择为空时的默认行为不明确

**问题表现**

用户可能不清楚未选择任何车间时的默认行为，容易误操作。

**解决方案**

- 保留原有逻辑：未选择任何车间时，保存空列表
- BroadcastCoordinator 在检测到空列表时，自动加载全部车间进行播报
- 界面不强制要求选择车间，保持可选项设计
- 操作按钮在没有数据时仍可用，只是不执行操作

**处理状态：已解决，与原有逻辑保持一致。**

## 四、车间选择功能使用流程

1. 用户打开设置表单
2. 填写 MES 地址、账号、密码（必须完整才能刷新车间列表）
3. 点击"刷新车间列表"按钮加载车间数据
4. 在左侧可用车间列表中选择车间，点击"添加 ->"移到右侧已选列表
5. 使用"全部添加"快速添加所有车间，使用"全部移除"清空已选列表
6. 在右侧已选列表中选择车间，点击"<- 移除"移回左侧
7. 点击"保存"完成配置
8. 未选择任何车间时，默认播报全部车间

## 五、当前正确的接口流程

与第 2 工作日一致：

1. `POST /loginWithNoCode`：使用账号密码登录并获取 Token。
2. `GET /mes/md/workshop/listAll`：获取车间并解析播报范围。
3. `POST /sys/voiceBroadcast/getNotBroadcastRecord`：查询 `state = 0` 的待播报任务。
4. 播放 `AlarmMusic.wav` 提示音。
5. 使用 Windows 中文 TTS 朗读任务 `content`。
6. 未达到 `voiceNum`：调用 `POST /system/voiceBroadcast/addBroadcastedNum`。
7. 达到 `voiceNum`：调用 `POST /system/voiceBroadcast/broadcastCompleted`。
8. 没有任务时按配置周期继续轮询；连续异常达到上限后暂停。

所有需要鉴权的请求均携带：

```http
Authorization: Bearer <token>
```
