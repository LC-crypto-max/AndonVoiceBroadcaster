安灯语音播报 - 操作员部署说明（2026-07-18）
==================================================

一、适用范围
--------------------------------------------------
本程序用于一台车间 Windows 电脑连接喇叭，自动查询 MES 安灯任务并进行中文语音播报。
建议由操作员按本文完成安装，由 MES 管理员提供服务地址、专用账号、工厂和车间范围。

二、目标电脑要求
--------------------------------------------------
1. 建议系统：Windows 10 或 Windows 11。
2. 运行框架：.NET Framework 4.8 或更高版本。
3. 语音组件：至少安装一个 Windows 中文语音。
4. 音频设备：喇叭/功放已连接，并设为 Windows 默认输出设备。
5. 网络：目标电脑能够访问 MES 服务地址。
6. 权限：当前 Windows 用户可以读写程序目录；不要求管理员身份运行程序。
7. 时间：Windows 日期、时间和时区设置正确。

.NET Framework 4.8 官方下载地址：
https://dotnet.microsoft.com/zh-cn/download/dotnet-framework/net48

三、交付文件
--------------------------------------------------
AndonVoiceBroadcaster/
├── AndonVoiceBroadcaster.exe    主程序
├── 安装检查.bat                  首次部署环境检查
├── 启动程序.bat                  日常启动入口
├── 部署说明.txt                  本说明
├── audio/
│   └── AlarmMusic.wav           提示音
└── config/
    └── appsettings.json         默认配置

以上文件应保持原有相对位置，不要只复制 EXE。

四、首次安装（建议 5-10 分钟）
--------------------------------------------------
1. 将压缩包完整解压到固定目录，建议 D:\AndonVoiceBroadcaster。
2. 双击“安装检查.bat”。
3. 如果提示缺少 .NET Framework 4.8，安装后重启电脑，再次运行检查。
4. 如果提示缺少中文语音：
   - Windows 10/11：设置 -> 时间和语言 -> 语言和区域 -> 中文 -> 语言选项；
   - 安装语音组件，完成后注销或重启电脑。
5. 确认关键检查项通过，再双击“启动程序.bat”。
6. Windows 防火墙如首次询问网络访问，只允许实际需要的受信任网络范围。

五、首次业务配置
--------------------------------------------------
1. 打开主界面，点击“系统设置”。
2. 填写 MES 服务地址、登录账号、密码和终端编号。
3. 点击“刷新列表”，等待工厂和车间加载完成。
4. 在工厂下拉框中确认当前工厂。
5. 在左侧选择车间，点击“添加 >”移入右侧；可用“全部 >>”快速全选。
6. 确认工作时间：上班开始 08:00，下班停止 17:00；如现场班次不同可修改。
7. 保存后回到主界面，检查状态信息是否显示正确。

说明：未选择任何车间时表示使用全部可用车间。工厂、车间和工作时间应按现场实际范围配置，防止漏播或跨区域播报。

六、现场验收
--------------------------------------------------
请按以下顺序逐项确认：

[ ] 点击“测试提示音”，喇叭能够播放提示音。
[ ] 点击“测试中文语音”，内容清晰、音量合适。
[ ] 设置页能够刷新并显示正确工厂。
[ ] 可用车间列表正确，添加、移除、全部选择和清空正常。
[ ] 保存后重新打开设置，工厂、车间和工作时间仍然正确。
[ ] 在工作时间内能够查询 MES 待播报任务。
[ ] 任务播报后，MES 播报次数及完成状态正确更新。
[ ] 关闭主窗口后程序进入托盘，右键托盘可安全退出。
[ ] 重启程序后日志目录和配置加载正常。

七、日常使用
--------------------------------------------------
1. 双击“启动程序.bat”。
2. 程序可按设置最小化到系统托盘；双击托盘图标可打开主界面。
3. 默认每天 08:00-17:00 自动查询和播报，其他时间保持等待。
4. 临时停止播报时点击“暂停播报”，恢复时点击“继续播报”。
5. 完全退出时，通过托盘右键菜单选择“退出程序”并确认。

八、程序运行后产生的文件
--------------------------------------------------
- data/credentials.dat：当前 Windows 用户 DPAPI 加密的 MES 登录凭据。
- logs/：运行日志，用于故障定位。

不要把 credentials.dat 复制给其他电脑或其他 Windows 用户；复制后通常无法解密，应在目标用户下重新输入账号密码。

九、常见问题
--------------------------------------------------
1. 程序打不开或提示缺少运行库
   - 运行“安装检查.bat”。
   - 安装 .NET Framework 4.8 后重启电脑。

2. 测试提示音没有声音
   - 检查喇叭电源、连接线、功放和 Windows 音量。
   - 在 Windows 声音设置中确认正确设备为默认输出。
   - 确认 audio\AlarmMusic.wav 存在且可以单独播放。

3. 提示音正常，但中文语音没有声音
   - 重新运行安装检查，确认存在中文语音。
   - 在 Windows 语言选项中安装中文语音组件并重启程序。

4. 无法连接 MES 或刷新列表失败
   - 检查 MES 地址、账号和密码。
   - 检查电脑网络、代理、防火墙和 MES 服务状态。
   - 确认账号具有租户/车间查询、播报任务查询和结果回写权限。
   - 查看 logs 目录中的最新日志。

5. 可以测试声音，但没有自动播报任务
   - 检查 Windows 时间和时区。
   - 检查当前时间是否处于设置的工作时间内。
   - 检查工厂和车间选择是否正确。
   - 确认所选车间存在待播报任务，并且没有被其他终端提前消费。

6. 程序退出后仍在托盘
   - 关闭主窗口仅表示最小化。
   - 请右键托盘图标，选择“退出程序”并确认。

十、升级与回退
--------------------------------------------------
1. 升级前先通过托盘完全退出程序。
2. 备份原程序目录中的 config、data 和 logs。
3. 使用新版本替换 EXE、audio 和部署脚本；如无明确说明，不覆盖现场已配置的 config 和 data。
4. 运行“安装检查.bat”，再启动并完成声音及 MES 联调验证。
5. 如新版本异常，退出程序后恢复上一版本目录，并将日志交给开发人员分析。

十一、技术支持需要收集的信息
--------------------------------------------------
- 故障发生时间和现场操作步骤；
- 主界面状态文字或截图；
- logs 目录中对应日期的日志；
- Windows 版本、.NET Framework Release 值；
- 工厂和车间名称（不要提供真实密码）。
