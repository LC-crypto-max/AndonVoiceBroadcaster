安灯语音播报 - 部署说明
================================

一、环境要求
------------
- 操作系统：Windows 7 SP1 及以上
- .NET Framework：4.8 或更高版本

二、快速部署
------------
1. 将压缩包解压到任意目录（建议：D:\AndonVoiceBroadcaster）
2. 双击运行 "启动程序.bat"
3. 程序会自动检查 .NET Framework 4.8 是否安装
4. 首次运行需要在系统设置中配置：
   - MES 服务地址
   - 登录账号和密码
   - 终端编号
   - 刷新并确认当前工厂
   - 选择要播报的车间（可选，不选则默认全部车间）
   - 确认上班时间为 08:00、下班停止时间为 17:00

三、文件结构
------------
AndonVoiceBroadcaster/
├── AndonVoiceBroadcaster.exe    # 主程序
├── 启动程序.bat                  # 启动脚本（含环境检查）
├── 部署说明.txt                  # 本说明文件
├── audio/
│   └── AlarmMusic.wav           # 提示音文件
└── config/
    └── appsettings.json         # 默认配置文件

四、配置说明
------------
首次运行后，程序会在当前目录下创建以下文件：
- data/credentials.dat    # 加密的登录凭据
- logs/                   # 运行日志目录

五、使用说明
------------
1. 启动程序后，主窗口会显示运行状态和待播报任务列表
2. 点击"测试提示音"可验证喇叭是否正常工作
3. 点击"测试中文语音"可验证中文语音是否正常
4. 点击"暂停/继续"可控制播报状态
5. 点击"系统设置"可修改配置
6. 每天 08:00-17:00 自动查询和播报，其他时间自动等待
7. 关闭主窗口会最小化到系统托盘
8. 右键点击系统托盘图标可退出程序

六、常见问题
------------
Q: 程序启动后没有声音？
A: 请检查：
   - 电脑是否安装了 .NET Framework 4.8
   - 系统音量是否打开
   - 是否安装了中文语音包（设置 -> 时间和语言 -> 语言 -> 中文 -> 选项 -> 添加语音）

Q: 无法连接 MES？
A: 请检查：
   - MES 服务地址是否正确
   - 登录账号和密码是否正确
   - 网络是否通畅
   - 登录账号是否有车间查询和语音播报权限

Q: 可以测试声音，但没有自动播报任务？
A: 请检查：
   - Windows 系统时间和时区是否正确
   - 当前时间是否在 08:00-17:00 之间
   - 工厂和车间范围是否正确
   - 选中车间是否存在有效产线和待播报任务

Q: 程序退出后进程仍在运行？
A: 请通过系统托盘右键菜单选择"退出程序"并确认，不要直接关闭窗口
